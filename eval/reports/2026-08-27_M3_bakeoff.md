## Verdict: single_pass

Accuracy tied at the ceiling, so cost decides. Single-pass uses **34% fewer
tokens** and **3x fewer requests** — and request count is the scarcer budget on
free tiers (per-minute and per-day request caps bind before token caps in this
workload). Sectioned also carries more moving parts (sectionizer heuristics,
fragment merge) for no measured benefit on this corpus.

**Caveat for the record:** this corpus is 1–2 page resumes that fit one context
window comfortably. On substantially longer documents the sectioned strategy's
smaller focused calls could win on accuracy; if the corpus ever grows multi-page
CVs, rerun this bake-off before trusting the verdict. The sectioned code path
stays in the codebase, tested, for exactly that case.
